# Hotel Management System

> Comprehensive hotel room operations, guest check-in/out, and reservation management system.

## Overview

A full-featured hospitality operations dashboard enabling hotel managers to track room occupancy, manage guest reservations, schedule housekeeping, and process billing transactions.

## Key Features

- Real-time room occupancy and availability visual grid
- Guest booking calendar with check-in, check-out, and stay extension controls
- Billing and invoice calculation with amenity add-on tracking
- Role-based operational dashboards for front-desk and administration

## Architecture and Technology Stack

- **Core Technologies:** Next.js, React, TypeScript, Tailwind CSS, Shadcn UI

## Getting Started

### Prerequisites

Ensure you have the required runtime environment installed for this repository:
- Node.js (v18+) for JavaScript/TypeScript projects
- Python (3.10+) for Python services and agent workflows

### Installation

Clone the repository to your local machine:

```bash
git clone https://github.com/Yusra-Saleem/hotel-management-system.git
cd hotel-management-system
```

Install dependencies:

```bash
# For Node / Next.js projects
npm install

# For Python projects
pip install -r requirements.txt
```

### Running Locally

```bash
# Start local development server
npm run dev

# Or for Python entry points
python main.py
```
